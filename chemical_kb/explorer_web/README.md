# Alpha Explorer 前端

## 目标与结构

这是化工安全知识库的独立 React 页面，包含导航栏、全屏图谱、实体索引、来源详情、时间轴、快速搜索、数据分析和知识治理。顶栏提供浅色和深色外观切换，并在浏览器中记住选择。

- 前端源码：`chemical_kb/explorer_web/src/`
- 生产构建：`chemical_kb/explorer_web/dist/`
- API 和静态文件服务：`chemical_kb/app/explorer_api.py`
- 图谱渲染：Three.js + `react-force-graph-3d`
- UI：React 19、Lucide、定制 CSS
- 后端数据：原有审核 JSONL、文档元数据、关键词索引、RAG、Wiki 和案例库

## 工作区

1. **工作总览**：真实知识片段、已审核实体和关系、待审断言统计；保留首页布局，不显示随机引文。
2. **兴趣测试**：既有学习题目、题源和答题记录。
3. **智能检索**：现有关键词、向量、图谱融合问答与证据列表；支持快速片段检索。
4. **知识 Wiki**：已有 Wiki 阅读、生成、逐节审核。
5. **化学品专题**：知识概览、来源证据、事故资料、图谱与审核、草稿维护。
6. **图谱探索**：已审/全部视图、3D 画布、实体与关系过滤、搜索聚焦、节点邻居、关系来源、最短路径和时间点筛选。
7. **数据洞察**：资料结构、专题覆盖与可核实知识关联。
8. **多维分析**：维度组合、图表联动、明细、A/B 比较和原文追溯。
9. **危化品新闻**：新闻浏览、来源与覆盖、原文与同步版本记录。
10. **知识治理**：断言审核、实体与冲突、导出图谱。
11. **文档与数据**：数据样例、指标口径、文档上传与统计说明。

## 功能页随机引文

除工作总览外的 10 个功能页，每次进入或刷新显示一条随机引文：

- 中文引文显示完整中文原句；外文引文先显示原文，下一行显示中文译文，语言标记正确。
- 单条正文按内容自然折行，窄屏不截断；桌面最大宽度 820px。
- “原文与出处”可展开查看作者、篇目、语种和来源链接。
- 引文库共 100 条，中文 50、英语 25、法语 15、德语 10；按功能页主题分配。
- 同一浏览会话内优先避免与上次重复；刷新或离开重进可抽换；页内选项卡、查询参数和普通重渲染不重抽。会话存储不可用或值损坏时安全回退。
- 首页工作总览、导航和页面标题区原有结构保留；「图谱与治理」提供图谱浏览与审核入口。

## 启动

### 前端构建与测试

在 `chemical_kb/explorer_web` 目录执行：

```bash
npm ci
npm test
npm run build
```

`npm test` 运行引文库、单条抽签、页面入口和来源展示测试；`npm run build` 生成 `dist/`。开发使用 `npm run dev`，本地生产预览使用 `npm run preview`。

### 后端服务

前端从 `/api/summary`、`/api/graph`、`/api/search` 等接口读取真实数据。后端启动前，需要已有安装项目依赖的 Python 环境（Flask、检索与文档处理依赖）。在 `chemical_kb/` 目录执行：

```bash
python -m app.explorer_api --host 127.0.0.1 --port 8503
```

服务默认仅监听本机回环地址。需要从本机访问时，使用可替换的主机名建立隧道，文档中不记录实际部署主机、端口、账号或密钥：

```bash
ssh -N -L 8504:127.0.0.1:8503 user@server.example.com
```

将 `user@server.example.com` 替换为部署账号和主机名，然后打开 `http://127.0.0.1:8504/`。若改为非回环地址监听，服务要求设置 `CHEM_KB_API_KEY`。生产部署建议使用受管 WSGI 进程和反向代理。

## 维护要点

- 页面从真实接口读取数据。
- 审核和实体合并是持久化操作；人工确认后追加审核版本，最新版本立即影响图谱，历史记录保留。
- 老断言没有 `valid_from/valid_to` 时会继续显示；时间轴明确提示数据未标注生效日期。
- PDF 上传入口只保存到项目数据目录，后续分块建索引仍由原处理流程执行。
- 服务器当前 Neo4j 未连接时，图谱使用审核 JSONL 回退数据源；真实密码只通过 `NEO4J_PASSWORD` 环境变量传入。
- 快捷键 `Ctrl+K` / `Cmd+K` 打开搜索工作区与实体的命令面板。
- 原始资料、模型、索引、数据库和审核数据不随前端更新上传；大型文件由 Git LFS 管理。
